 Student Study Planner 📚

A responsive web application designed to help students organize their study tasks, track progress, and manage daily learning activities.

 Features

* Add and delete study tasks.
* Mark tasks as completed or undo completion.
* Organize tasks by subject.
* Filter tasks by All, Completed, and Pending.
* Track total, completed, and pending tasks.
* View study progress using a progress bar.
* Switch between Light Mode and Dark Mode.
* Save tasks and theme preferences using Local Storage.
* Responsive design for different screen sizes.

Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Browser Local Storage



Learning Outcomes

This project helped me practice JavaScript events, DOM manipulation, arrays, filtering, browser storage, and responsive web design.
